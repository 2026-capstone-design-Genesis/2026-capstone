# 🧪 폐 알루미늄 흰색 비율 분석 시스템 (Prototype)

## 📌 프로젝트 개요

본 프로젝트는 공장 컨베이어 벨트 상에서 이동하는 **폐 알루미늄 소재 중 흰색 비율을 자동으로 분석**하기 위한 컴퓨터 비전 기반 시스템을 목표로 한다.

영상 또는 이미지 데이터를 입력으로 받아, 특정 영역(ROI) 내에서 **흰색으로 분류되는 픽셀 비율을 계산**하여 품질 관리 및 분류 자동화에 활용하는 것을 목적으로 한다.

---

## 🎯 목표

* 폐 알루미늄 내 **흰색 비율 자동 측정**
* 수작업 검사 대체 및 효율 향상
* 향후 **실시간 공정 적용 가능성 검증**
